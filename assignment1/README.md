# Assignment 1: motor identification

Start with `robotics_lab5_240060.ipynb`. It contains the calculations, graphs and discussion.

## Measurements

`motor_data/` contains six recordings:

- M3: step runs 1 and 2, plus one square-wave run.
- M4: step runs 1 and 2, plus one square-wave run.

The M4 step pair is the original runs 3 and 4, renamed consistently as runs 1 and 2.
Each measurement row gives encoder angle in degrees, time in milliseconds and motor power in percent.
`battery.txt` records the battery readings and test conditions.

## Robot programs

- `motor_steps.qrs`: M4 step tests.
- `motor_signal.qrs`: M4 square-wave test.
- `programs/motor_steps_M3.qrs`: M3 step tests.
- `programs/motor_square_M3.qrs`: M3 square-wave test.
